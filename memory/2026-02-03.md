## Correção de Cookies Seguros (19:15 UTC)

### Problema
Erro ao acessar n8n: "Your n8n server is configured to use a secure cookie, however you are either visiting this via an insecure URL"

### Causa
- N8N_PROTOCOL=http (inseguro)
- n8n quer cookies seguros (HTTPS only)
- Conflito ao acessar HTTP não seguro

### Solução Aplicada
Adicionado `N8N_SECURE_COOKIE=false` ao .env do cliente smitti
Container n8n reiniciado

### Resultado
- ✅ Erro resolvido
- ✅ Acesso funcionando via HTTP
- ✅ Health check OK
- ✅ Learning LRN-20260203-003 registrado

### Comandos Executados
```bash
cd /opt/n8n-clientes/smitti
echo "N8N_SECURE_COOKIE=false" >> .env
docker-compose restart n8n
```
